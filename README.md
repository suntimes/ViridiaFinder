# 维里迪亚寻宝 Viridia Finder 0.5.1

Minecraft 1.20.4 / Fabric / Java 17，纯客户端。安装对应 Fabric API，退出游戏后将发布 JAR 放入 mods，删除旧版同名模组 JAR。无需服务端安装。安装包请从右侧 Releases 下载。

## 从当前位置搜寻

按 **F7** 开始扫描并从脚下的位置计算巡查路线。打开 **F8 → 从当前位置重算路线**，可在移动或传送后重新选择剩余候选的访问顺序。首页显示当前坐标、此次计算的起点和预计总航程。已经巡查或标记领取的位置会跳过。普通换站只重新连接下一海段。

路线使用主群岛的 Xaero 地表水域快照，以离起点最近的可用海格为入口。从岸上出发时需手动入水，预计航程从海面入口起算。主群岛加载距离按最多 10 个区块规划，具体覆盖取决于客户端当时收到的完整区块。模组比较多种访问顺序，并调整仍能覆盖同一组候选的停靠位置，按实际水路长度择短。在固定起点 X=-763、Z=1321，观测到 10 圈且水平扫描范围为 ±16 时，169 点验证中的水路由 34,102.5 格缩短至 23,874.6 格。该算法择优比较有限方案，实际用时还受游速、停靠和区块加载影响。

## 自动航行

在主群岛海图范围内入水，打开 **F8 → 自动航行**。多人服务器首次启用移动辅助时，请先取得服主或管理方对自动转向、游泳和激流的明确许可。选择「已获本服明确许可」后，决定会按服务器地址保存在本机，可从 F8 设置中撤销。Monumenta 的公开规则提到禁止带来不公平优势的模组，细则见官方 Discord。[游戏内规则说明](https://monumenta.wiki.gg/wiki/Getting_Started)

- 航行时沿当前海段转向并向前游泳。区域已经加载时停下补扫，然后继续下一段。
- 快捷栏有可用的激流三叉戟时，优先使用手中那一把。只有航点距离至少 32 格、朝向对齐且前方已加载水路通过检查，才会按正常蓄力尝试激流。两次尝试至少相隔 **4 秒**，失败也计入。没有可用三叉戟时继续游泳。
- 手动转动视角、按移动键、换槽、攻击或使用物品会交还控制。打开界面或窗口失焦时暂停。遇到阻挡、长时间无法接近航点时停止。可随时按 F7 停止搜寻与移动辅助。
- 借用的快捷栏槽位会在停站或停止时按情况恢复，手动换槽优先。中断已经达到蓄力门槛的使用动作时，原版可能释放最后一次激流。

## 地图与记录

小地图以玩家为中心，上方为北。灰点表示候选位置，黄色表示普通箱，橙红色表示陷阱箱，紫色和青色表示玩家标记的疑似和已确认宝藏。空心标记保留历史观察，已领取使用绿色空心标记。下方显示当前搜索区域的方位、水平直线距离和剩余候选数，转弯航点供自动航行内部使用。

**F8 → 箱子与候选记录** 可查看箱子坐标、标记领取、导出记录或扩大复查。剩余 0/169 表示候选巡查结束，宝藏领取数以服务器提示为准。需要复查时，范围至少扩大至水平±16、上下各24格，并保留已有记录。主手持维里迪亚之眼左键查询可更新轮次提示，满足刷新条件后归档。F8 设置中可查看或手动更新轮次。

## 排除固定道具箱

在 **F8 → 箱子与候选记录** 点击一条箱子记录，再点 **非宝藏，忽略**。该精确 X、Y、Z 坐标会从箱子边框、小地图容器标记、新发现提示和箱子定位中排除。忽略名单按服务器、维度和实例标签保存，换轮次或重启后继续生效。候选小点保留，周围区域及其他箱子继续扫描，忽略操作不会把整个候选标记为已巡查或已领取。

可在 **F8 → 设置 → 已忽略箱子 → 恢复** 撤销，换轮次后即使还没有扫描记录也能恢复。详细记录和导出中仍保留“非宝藏（已忽略）”，便于核查。若同一坐标以后确实出现需要寻找的箱子，请先恢复显示。模组不会根据日记标题自动认定或排除宝藏。

若此前把道具箱误标为“确认宝藏”或“已领取”，“非宝藏，忽略”会撤销该坐标的宝藏标记。有此错误领取标记且没有其他已领取箱子的候选会重新加入核查，其他箱子的领取记录保留。

也可输入 `/viridiafinder 忽略 <X> <Y> <Z>` 和 `/viridiafinder 恢复 <X> <Y> <Z>`。两个命令只改变当前实例的本地名单，不会操作箱子。

使用 `/viridiafinder` 打开首页，`/viridiafinder 结果` 打开记录，`/viridiafinder 路线` 从当前位置重算。使用 Tab 查看其他子命令。运行时只检查客户端已加载区域中的普通箱子和陷阱箱。

## 构建与验证

使用 Gradle 8.7 和 JDK 17：`gradle build`。首次构建需要下载依赖。Loom 1.6.12，Fabric Loader 0.15.11，Fabric API 0.97.2+1.20.4，Yarn 1.20.4+build.3。

`check` 调用 `verifySurvey` 可执行验证程序，通过 Fabric Knot 加载真实 Minecraft 类和混入；未采用 JUnit 测试发现。报告生成于 build/verification。验证包含真实候选数据库的海路测距、模拟水域碰撞、激流间隔和快捷栏选择。航行手感、服务器延迟和实际搜索用时仍需在游戏中验证。

`tools/import_xaero_water.py` 用于读取本地 Xaero 地表区域并生成水域资源，仅支持已检查的格式版本。`tools/render_water_route.py` 用于生成路线预览。运行脚本时先查看参数；导入后的资源需替换 src/main/resources/assets/viridiafinder/isles-water.bin 并重新构建。没有实时 Xaero 依赖。
